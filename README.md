# StudyNook

StudyNook is a full-stack study room booking platform built with React, Node.js, Express and MongoDB.

## Features

- User registration and login
- Browse and search study rooms
- Filter rooms by amenities, floor and price
- Add, edit and delete owned rooms
- Book rooms with date and time slots
- Prevent overlapping bookings
- Manage and cancel personal bookings
- Responsive design

## Technologies

- React
- Vite
- Tailwind CSS
- DaisyUI
- Node.js
- Express.js
- MongoDB
- JWT
- Firebase Authentication
